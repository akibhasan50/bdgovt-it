**Cloud Computing** is on-demand access to shared computing resources over the Internet — servers, storage, databases, networking, and software — that can be rapidly provisioned with minimal management effort.

<Callout type="tip">
Primary exam anchors: deployment + service models *(CB O(IT) 26)* · enabling technologies *(CB AME 2026)*.
</Callout>

## What is Cloud Computing

Instead of owning physical hardware, users and organisations **rent** computing power and storage from a cloud provider and pay for what they use. Resources live in remote data centres and are reached over the Internet.

## Key Characteristics

The five defining characteristics of cloud computing:

| Characteristic | Meaning |
|----------------|---------|
| **On-demand self-service** | Users provision resources automatically without talking to the provider |
| **Broad network access** | Available over the network from any device (laptop, phone, tablet) |
| **Resource pooling** | One provider's resources serve many users (multi-tenancy) |
| **Rapid elasticity** | Capacity scales up or down quickly with demand |
| **Measured service** | Usage is metered — you pay for what you consume |

## Deployment Models

*Question tagged: CB O(IT) 26*

| Model | Who uses it | Traits |
|-------|-------------|--------|
| **Public** | Open to any user/organisation over the Internet | Owned by third-party providers (AWS, Azure, GCP); pay-as-you-go; shared infrastructure |
| **Private** | Single organisation only | More control and security; hosted in-house or by a provider; higher cost |
| **Hybrid** | Mix of public and private | Sensitive data stays private; burst capacity goes to public; flexibility + compliance |
| **Community** | Organisations with shared goals | Shared infrastructure for groups with common requirements (e.g. government agencies) |

## Service Models: IaaS, PaaS, SaaS

*Question tagged: CB O(IT) 26*

| Model | What you get | Who maintains | Example tasks |
|-------|--------------|---------------|---------------|
| **IaaS** (Infrastructure as a Service) | Rent IT infrastructure — servers, storage, networks | Provider runs the hardware; **users install OS and applications** | Virtual machines, block/file storage |
| **PaaS** (Platform as a Service) | Ready platform for developers to **build and deploy** applications | Provider manages OS, runtime, middleware; you manage code | App platforms, databases-as-a-service |
| **SaaS** (Software as a Service) | **Ready-to-use applications** delivered over the Internet | Provider maintains everything; **no hardware or software maintenance** by the user | Webmail, online office suites |

<Callout type="warning">
Exam trap: IaaS = *infrastructure only* (you install OS/apps). PaaS = *build on the platform*. SaaS = *use the app* — the user does **not** maintain hardware or software.
</Callout>

## Advantages of Cloud Computing

| Advantage | What it means |
|-----------|---------------|
| **Lower cost** | No big upfront hardware purchase; pay only for usage |
| **High performance & security** | Provider data centres offer robust hardware and security controls |
| **Data backup & recovery** | Built-in backup and disaster-recovery options |
| **Access anywhere** | Data and apps reachable from any location with Internet |
| **Flexible capacity** | Scale up or down on demand (rapid elasticity in practice) |
| **Productivity & innovation** | Teams ship faster without managing infrastructure |

## Disadvantages of Cloud Computing

| Disadvantage | Risk |
|--------------|------|
| **Internet dependence** | No connection → no access to resources |
| **Limited control** | Users have little say over the underlying infrastructure |
| **Security concerns** | Data leaves the organisation's premises; shared-tenant risks |

## Enabling Technologies

*Question tagged: CB AME 2026*

Cloud computing is made possible by:

1. **Virtualization** — one physical machine runs many isolated virtual machines
2. **Service-Oriented Architecture (SOA)** — software delivered as reusable services
3. **Grid & utility computing** — many machines pooled as one; metered like a utility
4. **Broadband networks** — high-speed Internet makes remote access practical
5. **The Internet** — the universal transport between user and data centre

## Past Exam Questions

**Q1:** What are the different deployment models of cloud computing? *(CB O(IT) 26)*

**A:** Four models — **Public** (open to any user over the Internet, third-party provider), **Private** (one organisation, more control/security), **Hybrid** (mix of public and private for flexibility + compliance), **Community** (shared by organisations with common goals).

**Q2:** Explain IaaS, PaaS, and SaaS with examples. *(CB O(IT) 26)*

**A:** **IaaS** — rent IT infrastructure (servers, storage, networks); users install their own OS and applications. **PaaS** — a platform where developers build and deploy applications; the provider manages the runtime. **SaaS** — ready-to-use software over the Internet; the user maintains no hardware or software.

**Q3:** What are the enabling technologies of cloud computing? *(CB AME 2026)*

**A:** Virtualization, service-oriented architecture, grid and utility computing, broadband networks, and the Internet.

**Q4:** State four advantages and two disadvantages of cloud computing.

**A:** *Advantages:* lower cost, high performance/security, data backup and recovery, access from anywhere (also flexible capacity, productivity). *Disadvantages:* dependence on the Internet, limited user control, security concerns.

**Q5:** What is cloud computing? List its key characteristics.

**A:** On-demand access to shared computing resources (servers, storage, databases, networking, software) over the Internet with minimal management effort. Characteristics: on-demand self-service, broad network access, resource pooling, rapid elasticity, measured service.
