## Sets & relations

- Power set of n elements → **2ⁿ** subsets.
- |A ∪ B| = |A| + |B| − |A ∩ B|.
- Relation properties: reflexive, symmetric, antisymmetric, transitive → equivalence relation needs all-but-antisymmetric (reflexive + symmetric + transitive).

## Logic & proofs

De Morgan, contrapositive (`p → q` ≡ `¬q → ¬p`), and the difference between converse and inverse. Proof by induction: base case + inductive step — appears in algorithm correctness questions.

<Callout type="tip">
P(A ∪ B) = P(A) + P(B) holds **only** for mutually exclusive events. Independent events use P(A)P(B) for the intersection.
</Callout>

## Combinatorics

```text
Permutation of n things taken r:  nPr = n! / (n−r)!
Combination:                      nCr = n! / (r!(n−r)!)
Sum of geometric series:          a(rⁿ − 1)/(r − 1)
```

Binomial theorem coefficient of xᵏ in (a+b)ⁿ is C(n,k)·aⁿ⁻ᵏ·bᵏ.

## Graph theory

- **Handshaking lemma**: sum of degrees = 2|E| (so any graph with an odd number of odd-degree vertices... wait — the sum is always even; odd-degree vertices always come in pairs).
- Complete graph Kₙ has n(n−1)/2 edges.
- Tree with n vertices has exactly n−1 edges.
- Euler path needs 0 or 2 odd-degree vertices; Euler **circuit** needs all even.

<Callout type="info">
"6 vertices, every degree 3 → edges?" → (6×3)/2 = 9. Handshaking is one line and shows up yearly.
</Callout>

## Number theory

GCD via Euclid's algorithm, LCM × GCD = product of numbers (two-number case), modular arithmetic for cryptography chapters (RSA relies on it).

### Algebra drills [BKKB AP 2026]

**Q: If `a − 1/a = 2`, find `a⁴ + 1/a⁴`.**

**Answer:** `34`

**Solution:**

```text
Given:   a − 1/a = 2

Step 1 — square both sides:
  (a − 1/a)² = 2²
  a² − 2·a·(1/a) + 1/a² = 4
  a² − 2 + 1/a² = 4
  a² + 1/a² = 6

Step 2 — square again:
  (a² + 1/a²)² = 6²
  a⁴ + 2·a²·(1/a²) + 1/a⁴ = 36
  a⁴ + 2 + 1/a⁴ = 36
  a⁴ + 1/a⁴ = 34
```

**Related info:**

| Given | After 1st square | After 2nd square |
| --- | --- | --- |
| `a − 1/a = k` | `a² + 1/a² = k² + 2` | `a⁴ + 1/a⁴ = (k²+2)² − 2` |
| `a + 1/a = k` | `a² + 1/a² = k² − 2` | `a⁴ + 1/a⁴ = (k²−2)² − 2` |

**Method:** **square twice** — the cross term is always `±2` and cancels the constant you need to move. Same pattern for `a³ ± 1/a³` (multiply the linear expression by the square).
