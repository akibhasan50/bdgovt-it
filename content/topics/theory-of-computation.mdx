## What TOC is for

Automata Theory (Theory of Computation) studies abstract machines to map the **capabilities and limitations** of computation: which problems a computer can solve, how, and at what time/memory cost. Objectives to quote in written answers — design compilers and language processors; separate solvable from unsoluble problems; compare efficiency of solutions; provide the theoretical foundation for computing. Classic exam example: verifying whether an entered password is correct.

## Core vocabulary

| Term | Meaning |
| --- | --- |
| Symbol | indivisible unit — a letter, digit or character |
| Alphabet `Σ` | finite, non-empty set of symbols (`{a,b}`, `{0,1}` binary alphabet) |
| String `w` | finite sequence over an alphabet; length `|w|` counts symbols |
| Empty string `ε` | no symbols; `|ε| = 0` |

Strings of length n over a 2-symbol alphabet number `2ⁿ` — Σ = `{a,b}` gives 4 at n=2, 8 at n=3.

**Closures** — the two every paper drills:

| Feature | `L+` (positive) | `L*` (Kleene star) |
| --- | --- | --- |
| Minimum repeats | one | zero |
| Includes `ε` | no | yes |
| Regex over `{g}` | `g+` → `{g, gg, ggg, …}` | `g*` → `{ε, g, gg, …}` |

`L* = ε ∪ L+`. Kleene star is a unary operator underpinning regex, finite automata, lexical analysers, pattern matching.

## Languages & the Chomsky hierarchy

A language is a set of strings over `Σ`, formally `L ⊆ Σ*`. Finite (a handful of strings) or infinite ("all strings starting with b").

```text
Type 0  Recursively enumerable   — Turing machine
Type 1  Context-sensitive        — LBA
Type 2  Context-free             — PDA / CFG
Type 3  Regular                  — DFA, NFA, regex
```

Each level is a strict subset of the one above: regular ⊂ CFL ⊂ CSL ⊂ RE.

| Language type | Generated by | Recognised by |
| --- | --- | --- |
| Regular | regular expression | finite automata (FA) |
| Context-free | context-free grammar (CFG) | pushdown automaton (PDA) |
| Context-sensitive | context-sensitive grammar (CSG) | linear bounded automaton (LBA) |
| Recursive / RE | Turing machine | Turing machine (TM) |

Recursive = the TM **always halts** with a decision; recursively enumerable = accepts valid strings but may loop forever on invalid ones.

## Recognisers

- **DFA/NFA** — finite state, no memory beyond state → regular languages.
- **PDA** — one stack → context-free languages.
- **Turing machine** — infinite tape → anything computable (and the halting problem isn't).

<Callout type="tip">
"If a PDA can't but a TM can" → context-sensitive or beyond. The one-stack limit is the whole trick.
</Callout>

## Finite automata, DFA & NFA

FA = pattern recognizer reading one symbol at a time; end in an accepting state → accept, else reject. Formal **5-tuple**:

```text
FA = {Q, Σ, q0, F, δ}     δ : Q × Σ → Q
```

Q = states, Σ = alphabet, q0 = unique start state, F = accepting states (one or more), δ = transition function — e.g. `δ(q0, a) = q1`.

| Feature | DFA | NFA |
| --- | --- | --- |
| Transitions per symbol | exactly one | zero, one or many |
| ε-transition | **not allowed** | allowed |
| Paths per input | single, unique | many explored at once |
| Acceptance | only the one path must accept | **at least one** path accepts |
| Transition function | `δ : Q × Σ → Q` | `δ : Q × (Σ ∪ {ε}) → 2^Q` |
| Relationship | every DFA is an NFA | not every NFA is a DFA |
| Construction | harder | easier |
| Regex → automaton | harder | simpler |

Worked NFA — strings over `{a,b}` **ending in a**: Q = `{q0,q1}`, start q0, final q1; on `a` from q0 go `{q0,q1}`, on `b` stay `{q0}`. Trace "bba" reaches q1 → accepted; "abb" ends on b → rejected. DFA/NFA both recognise exactly the regular languages.

<Callout type="info">
Classic constructions to practise: DFA for binary strings ending with 1 (accept 1, 01, 101; reject 0, 10, 1100); DFA for strings starting with 0; NFA/DFA for strings starting **or** ending with 01.
</Callout>

## Pumping lemma intuition

Used to prove a language is *not* in a class: `{aⁿbⁿcⁿ}` fails the CFL pumping lemma but is context-sensitive. Pumping lemma for regular languages handles `{0ⁿ1ⁿ}`.

## Decidability

- **Decidable** — TM always halts with yes/no (emptiness for regular/CFL, equivalence for regular).
- **Undecidable** — no TM decides it: **halting problem**, equivalence for CFLs, emptiness for CSL.

<Callout type="warning">
Halting problem = undecidable. Rice's theorem generalises: any non-trivial semantic property of RE languages is undecidable.
</Callout>

## GNF/CNF

Any CFG can be converted to Greibach or Chomsky normal form. CNF: only `A→BC` and `A→a`. Conversion steps themselves occasionally appear as multi-part questions.

## Past-paper drills

1. **Regular expression** [Janata ASA-2021] — `{w | w has at least two a's, or exactly two b's}`:
   - at least two a's: `(b|a)* a (b|a)* a (b|a)*`
   - exactly two b's: `a* b a* b a*`
   - union of the two.
2. **Ambiguous grammar** [Combined Bank SO(IT) 2024] — with `E → E + E | E * E | id`, the string `id + id * id` has two parse trees: one groups the sum first `(id+id)*id`, one groups the product first `id+(id*id)` → grammar is ambiguous (same string, more than one parse tree / leftmost derivation).
3. **Zeros multiple of 3** [6 Bank & FI AP-2021] — binary strings where the number of 0s is a multiple of 3: `1*(01*01*01*)*1*` — inner group holds exactly three 0s (1s allowed between), the outer star repeats the group; accepts ε, 111, 000, 010010; rejects 0, 00, 0000.
4. **DFA construction** [CB SO(IT) 2022] — language where every `a` is followed by at least two `b`s over `{a,b}`: draw states so each `a` forces a two-`b` countdown before another `a` is allowed.
