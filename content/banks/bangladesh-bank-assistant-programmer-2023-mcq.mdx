**Q17: Which of the following is not the required condition for a binary search algorithm?**

- **(A)** The list must be sorted
- **(B)** There should be direct access to the middle element in any sublist
- **(C)** There must be a mechanism to delete and/or insert elements in the list
- **(D)** Number values should only be present

**Answer:** **(C) There must be a mechanism to delete and/or insert elements in the list**

**Explanation:** Binary searching is a technique used on a sorted array by dividing the search interval in half. The algorithm only requires that the list is sorted and allows direct access to the middle element. Deleting or inserting elements is not necessary for a binary search, so option (c) is the correct answer.

**Q21: Design pattern for hierarchical structure is _____**

- **(A)** Structure chart
- **(B)** DFD
- **(C)** ERD
- **(D)** UML

**Answer:** **(A) Structure chart**

**Explanation:** A Structure chart is a chart derived from a Data Flow Diagram (DFD). It represents the system in more detail than a DFD. It breaks down the entire system into the lowest functional modules, describes functions, and sub-functions of each module of the system in greater detail than a DFD. The structure chart represents the hierarchical structure of modules. At each layer, a specific task is performed.

**Q22: How many addresses are there in the network 200.10.10.10/20?**

- **(A)** 4096
- **(B)** 1024
- **(C)** 2048
- **(D)** 1022

**Answer:** **(A) 4096**

**Explanation:** The subnet mask is "/20," which means that the first 20 bits of the IP address are used to identify the network, and the remaining 12 bits are used to identify hosts within that network. To calculate the number of IP addresses in this network, we need to determine how many bits are used to identify hosts, which is 12 in this case. The number of possible host addresses is 2^12, since the first and last addresses in the subnet are reserved for the network address and the broadcast address, respectively. Total Address Calculation: 2^12=4096

**Q23: Which is suitable subnet mask for 200 hosts?**

- **(A)** 255.255.0.200
- **(B)** 255.255.255.0
- **(C)** 255.0.0.0
- **(D)** 255.255.200.0

**Answer:** **(B) 255.255.255.0**

**Explanation:** A subnet mask of 255.255.255.0 allows for 254 host addresses, which can accommodate 200 hosts. Therefore, option (b) is the correct choice.

**Answer:** **(C) garbage values**

**Explanation:** Using post-increment operations on uninitialized variables results in undefined behavior, producing garbage values.
