## Multiple choice questions (Q1–Q100)

**Q1: Which one is not an ACID property?**

- **(A)** Authenticity
- **(B)** Consistency
- **(C)** Isolation
- **(D)** Durability

**Answer:** **(A) Authenticity**

**Explanation:** ACID stands for: Atomicity – Transaction is all-or-nothing Consistency – Database remains valid before and after transaction Isolation – Concurrent transactions do not interfere Durability – Committed data is permanent Note: Authenticity relates to security, not transaction management. Therefore, it is not part of ACID.

**Q2: Which of the following is a guided transmission medium?**

- **(A)** Radiowave
- **(B)** Microwave
- **(C)** Coaxial Cable
- **(D)** Infrared

**Answer:** **(C) Coaxial Cable**

**Explanation:** Guided media use physical cables to transmit signals. Coaxial cable is a physical wired medium. Radiowave, Microwave, and Infrared are wireless (unguided) media.

**Q3: In C, to retain the values of variables between function calls, we should use:**

- **(A)** auto
- **(B)** extern
- **(C)** static
- **(D)** register

**Answer:** **(C) static**

**Explanation:** A static variable inside a function: Is initialized only once Retains its value between function calls Stored in static memory area Note: auto and register are temporary. extern is used for global variables across files.

**Explanation:** Thrashing occurs when: Too many page faults happen RAM is insufficient System continuously swaps pages between disk and memory CPU stays busy swapping instead of executing programs.

**Q44: The main difference between a latch and a flip-flop is**

- **(B)** FF is edge-triggered, L is level-triggered
- **(C)** FF cannot store data but L can
- **(D)** L can store more data than FF

**Answer:** **(B) FF is edge-triggered, L is level-triggered**

**Explanation:** Latch vs Flip-Flop: A Latch is level-triggered: its output changes whenever the enable signal is active and it is sensitive to the level of the clock/enable input. A Flip-Flop (FF) is edge-triggered: it changes output only at a specific clock transition (rising or falling edge) and is not continuously sensitive to clock level. Other options are incorrect because both latch and flip-flop store 1 bit of data; the real difference is the triggering mechanism (level vs edge).

**Q61: Contrapositive of "If it rains, the home team wins":**

- **(A)** If the home team wins, then it rains
- **(B)** If the home team does not win, it does not rain
- **(C)** If it does not rain, then the home team does not win
- **(D)** The home team wins whenever it rains

**Answer:** **(B) If the home team does not win, it does not rain**

**Explanation:** The original statement is: If P then Q (If it rains → the home team wins). The contrapositive of “If P then Q” is “If not Q then not P”. Here, not Q = home team does not win, and not P = it does not rain. Therefore, the correct contrapositive is: If the home team does not win, it does not rain.
