## Multiple choice questions (Q1–Q99)

**Q1: OOP stands for:**

- **(A)** Object Oriented Programming
- **(B)** Open Office Protocol
- **(C)** Object Operating Program
- **(D)** Output Oriented Process

**Answer:** **(A) Object Oriented Programming**

**Explanation:** Object Oriented Programming (OOP) is a programming approach that organizes software into objects containing both data and methods, making programs easier to design, reuse, and maintain. Open Office Protocol is a set of standards for office software communication. Object Operating Program is not a standard term in programming. Output Oriented Process refers to a process focused on results, not a programming paradigm.

**Q2: Which attack floods a system with traffic?**

- **(A)** Phishing
- **(B)** DOS
- **(C)** Spoofing
- **(D)** Sniffing

**Answer:** **(B) DOS**

**Explanation:** A Denial of Service (DoS) attack floods a system with excessive traffic to make it slow or unavailable to legitimate users. Phishing is an attack that tricks users into revealing sensitive information. Spoofing is pretending to be another user or device to gain access. Sniffing is intercepting and capturing network data for analysis or theft.

**Q3: HTTPS is more secure than HTTP because it uses:**

- **(A)** IP
- **(B)** Encryption
- **(C)** Cookies
- **(D)** Proxy

**Answer:** **(B) Encryption**

**Explanation:** Encryption converts data into a secure coded form, preventing unauthorized users from reading the information during transmission. IP (Internet Protocol) is used to identify and locate devices on a network so data can be sent to the correct destination. Cookies are small files stored in a user’s browser to remember login details, preferences, and session information. A proxy server acts as an intermediary between a user and the internet, forwarding requests and responses.

**Q4: Firewall is used to:**

- **(A)** Store data
- **(B)** Monitor network traffic
- **(C)** Compile programs
- **(D)** Create backups

**Answer:** **(B) Monitor network traffic**

**Explanation:** Monitoring network traffic means observing and controlling data flow to protect systems from unauthorized access and attacks. Storing data refers to saving information in databases or storage devices for future use. Compiling programs involves converting source code into machine code using a compiler. Creating backups means making copies of data so it can be restored if the original data is lost.

- **(D)** 3

**Answer:** **(D) 3**
