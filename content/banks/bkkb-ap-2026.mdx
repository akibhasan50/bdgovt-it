## English (Q1–Q4 pattern)

**Q1: Bread made \_\_\_ wheat.**

**Answer:** **from**

**Explanation:** Use **"from"** when the original material changes form during the process. Bread is made **from** wheat — the wheat no longer looks like wheat in the loaf.

**Related info:**

| Phrase | Meaning | Example |
| --- | --- | --- |
| **made from** | material transforms | paper made from wood |
| **made of** | material still recognisable | a table made of wood |
| **made with** | ingredient added | cake made with butter |

**Exam tip:** *Bread is made **from** wheat.* Memorise the trio from / of / with with one example each.

## Mathematics (algebra drill)

**Q28: If `a − 1/a = 2`, find `a⁴ + 1/a⁴`.**

**Answer:** **34**

**Explanation / solution:**

```text
Given:  a − 1/a = 2

Square:  a² − 2 + 1/a² = 4   →   a² + 1/a² = 6

Square:  a⁴ + 2 + 1/a⁴ = 36  →   a⁴ + 1/a⁴ = 34
```

**Related info:**

| Given | After 1st square | After 2nd square |
| --- | --- | --- |
| `a − 1/a = k` | `a² + 1/a² = k² + 2` | `a⁴ + 1/a⁴ = (k²+2)² − 2` |
| `a + 1/a = k` | `a² + 1/a² = k² − 2` | `a⁴ + 1/a⁴ = (k²−2)² − 2` |

**Exam tip:** **Square twice** — cross term is always ±2. Same skeleton for cubes via `(a±1/a)(a²±1/a²)`.

## Technical — Programming & OS

**Q16: Which is the fastest sorting algorithm among Bubble, Selection, Quick and Insertion?**

**Answer:** **Quick Sort**

**Explanation:** Quick sort averages **O(n log n)**; Bubble, Selection, and typical Insertion average **O(n²)**.

**Related info:**

| Algorithm | Average | Worst |
| --- | --- | --- |
| Bubble | O(n²) | O(n²) |
| Selection | O(n²) | O(n²) |
| Insertion | O(n²) | O(n²) |
| **Quick** | **O(n log n)** | O(n²) |

**Exam tip:** *Fastest in practice among these four* → Quick. Worst case still O(n²) on bad pivots.

**Q17: Convert binary `101011` into decimal.**

**Answer:** **43**

**Explanation:** Each bit is a power of 2, counted from the right (position 0):

| Bit position | 5 | 4 | 3 | 2 | 1 | 0 |
| --- | --- | --- | --- | --- | --- | --- |
| Bit value | 1 | 0 | 1 | 0 | 1 | 1 |
| Contribution | 32 | 0 | 8 | 0 | 2 | 1 |

`101011₂ = 32 + 0 + 8 + 0 + 2 + 1 = **43**`

**Related info:**

| Base | System | Quick check |
| --- | --- | --- |
| 2 | Binary | digits 0–1 |
| 8 | Octal | group bits in 3s |
| 10 | Decimal | our normal numbers |
| 16 | Hex | digits 0–F, group bits in 4s |

**Exam tip:** Always write powers under the bits before summing — place-value errors are the classic trap (`101011` looks like `43` not `42`/`44`).

**Q40: Simplify: (A + AB)(B + AB)**

**Answer:** **AB**

**Explanation:** Absorption: `A + AB = A` and `B + AB = B`, so the product is `A · B = AB`.

**Related info — absorption laws:**

```text
A + AB = A
A(A + B) = A
A + A'B = A + B
```

**Exam tip:** Spot the redundant term inside the OR — absorption kills it in one step.

**Q49: Memory-size related question (stem/options incomplete on the released key)**

**Answer:** Stem incomplete — memorise the standard unit ladder anyway:

```text
1 Byte = 8 bits
1 KB   = 1024 Bytes
1 MB   = 1024 KB
1 GB   = 1024 MB
1 TB   = 1024 GB
```

**Explanation:** Memory MCQs almost always ask one of two shapes: (1) *convert 1 GB → MB/KB*, or (2) *how many bytes can an address of N bits select?* For (2) capacity = `2^N` bytes (assuming byte-addressable).

**Related info:**

| Address width | Byte-addressable capacity |
| --- | --- |
| 16 bit | 2¹⁶ = 64 KB |
| 20 bit | 2²⁰ = 1 MB |
| 32 bit | 2³² = 4 GB |
| 64 bit | 2⁶⁴ = 16 EB (theoretical) |

**Exam tip:** Learn `2^width` for address buses and `1024 = 2^10` for file sizes — covers both MCQ shapes even when the printed stem is cut off.
