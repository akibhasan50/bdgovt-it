**Q6: If log₄(x) = 12 then find log₂(x / 4)**

- **(A)** 22
- **(B)** 23
- **(C)** 26
- **(D)** 12

**Answer:** **(A) 22**

**Explanation:** log₄ x = 12 ⇒ x = 4¹², so log₂(x/4) = log₂(4¹¹) = 22 — option A. (The source prints log₂(4/x), which would be −22; the intended expression is log₂(x/4).)
