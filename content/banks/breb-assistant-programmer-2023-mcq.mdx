## Multiple choice questions (Q1–Q18)

**Q1: How many bits of IPv6 address?**

- **(A)** 128
- **(B)** 32
- **(C)** 12
- **(D)** 48

**Answer:** **(A) 128**

**Explanation:** IPv6 addresses are 128 bits long, providing a significantly larger address space compared to IPv4, which uses 32-bit addresses.

**Q2: Which one is a Private IP address?**

- **(A)** 192.168.10.10
- **(B)** 11.15.10.10
- **(C)** 1.1.1.1
- **(D)** 172.16.5.3

**Answer:** **(A) 192.168.10.10**

**Explanation:** Private IP addresses are used in local networks and are not routable on the public internet. The IP address 192.168.10.10 is part of the private range (192.168.0.0 to 192.168.255.255). The others are public IP addresses.

**Q3: Which algorithm is used in memorization?**

- **(A)** Dynamic Programming
- **(B)** Backtracking
- **(C)** Static Programming
- **(D)** Xtreme Programming

**Answer:** **(A) Dynamic Programming**

**Explanation:** Dynamic Programming is an algorithmic technique where a problem is divided into smaller subproblems, which are solved once and stored for future use. This helps reduce the time complexity of solving larger problems.

**Q4: What does a block in a Blockchain?**

- **(A)** A blockchain is a centralized digital ledger consisting of records called blocks
- **(B)** A blockchain is a decentralized, distributed, digital ledger consisting of records called blocks
- **(C)** A blockchain is a centralized digital ledger consisting of records called blocks
- **(D)** None of the above

**Answer:** **(B) A blockchain is a decentralized, distributed, digital ledger consisting of records called blocks**

**Explanation:** A blockchain is a decentralized, distributed database consisting of ordered records (blocks) that are linked cryptographically. It ensures transparency and security for transactions.

**Q6: Which protocol in data encryption of Network level?**

- **(A)** HTTPS
- **(B)** DNS
- **(C)** SMTP
- **(D)** FTP

**Answer:** **(A) HTTPS**

**Explanation:** HTTPS (HyperText Transfer Protocol Secure) is used for secure communication over a computer network, encrypting data at the network level.

**Q8: Which of the following sort algorithms has execution time that is least dependent on initial ordering of the input?**

- **(A)** Merge Sort
- **(B)** Insertion Sort
- **(C)** Selection Sort
- **(D)** Quick Sort

**Answer:** **(A) Merge Sort**

**Explanation:** Merge Sort has a time complexity of O(n log n) in the worst, best, and average cases, making it least dependent on the initial ordering of the input compared to others, which might have worse performance in some cases.

**Q10: Universal logic gate is:**

- **(A)** NAND, XOR
- **(B)** NOR, XOR
- **(C)** NOR, OR
- **(D)** NAND, NOR

**Answer:** **(D) NAND, NOR**

**Explanation:** NAND and NOR gates are universal because they can implement any Boolean function without the need for other gates.
