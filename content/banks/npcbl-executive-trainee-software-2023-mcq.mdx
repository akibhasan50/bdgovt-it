## Multiple choice questions (Q1–Q41)

**Q1: Address stored in the pointer variable is of type:**

- **(A)** Integer
- **(B)** Character
- **(C)** Double
- **(D)** float

**Answer:** **(A) Integer**

**Explanation:** In most programming languages, the address stored in a pointer variable typically refers to the location of a memory address, which is usually represented as an integer (memory address). This could be a byte address or a pointer to an object, but it is generally treated as an integer value.

**Q2: The number of values a function can return at a time?**

- **(A)** 1
- **(B)** 2
- **(C)** 0
- **(D)** more than 2

**Answer:** **(A) 1**

**Explanation:** A function can return only one value at a time. While a function may have multiple return statements, it can only return one value per call, even if it appears to return more values through different mechanisms like returning objects or arrays.

**Q4: The degree of interaction between two modules is known as:**

- **(A)** Cohesion
- **(B)** Strength
- **(C)** Inheritance
- **(D)** Coupling

**Answer:** **(D) Coupling**

**Explanation:** Coupling refers to the degree of interdependence between software modules. Strongly coupled modules are tightly dependent on each other, while loosely coupled modules are independent of each other. Uncoupled modules have no interdependence.

**Q7: What is the maximum number of IP addresses that can be assigned to the host on a local subnet that uses the 255.255.255.224 subnet mask?**

- **(A)** 16
- **(B)** 32
- **(C)** 31
- **(D)** 30

**Answer:** **(D) 30**

**Explanation:** A /27 subnet mask (255.255.255.224) provides 8 subnets, each with 30 hosts. The 5 remaining bits after allocating for subnets allow for 30 usable IP addresses per subnet (subtracting the network and broadcast addresses).

**Q25: What will be the output of the following C code fragment? x = 0; while (x \< 100) x += 2; print(x);**

- **(A)** 99
- **(B)** 100
- **(C)** 101
- **(D)** 98

**Answer:** **(B) 100**

**Explanation:** The loop increments x by 2 in each iteration, starting from 0. The loop runs until x reaches or exceeds 100. The first time the loop increments x to 100, the condition x \< 100 is no longer true, and the loop exits. Therefore, print(x) outputs 100.

**Q26: When a class serves as a base class for many derived classes, the situation is called:**

- **(C)** Hybrid inheritance
- **(D)** Multipath inheritance

**Answer:** **(B) Hierarchical inheritance**

**Explanation:** Hierarchical inheritance occurs when multiple derived classes inherit from a single base class. This is like having different fruits (apple, mango) inheriting properties from a common base class (fruit).

**Answer:** **(D) 7**
