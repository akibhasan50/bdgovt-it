**Q1: Which country is known as the 'Rainbow Nation'?**

**Q2: Which one of the following is related to the services provided by the cloud?**

**Explanation:** "PaaS" stands for "Platform as a Service." It’s a cloud computing service that allows users to develop, run, and manage applications without the complexities of building and maintaining the underlying infrastructure, which is managed by a third-party provider.

**Q7: A basic memory storage element in a digital system is:**

- **(A)** Flip-flop

- **(C)** Multiplexer
- **(D)** Encoder

**Answer:** **(A) Flip-flop**

**Explanation:** Flip-flop is a digital storage element with two stable states, used to store a single bit of information. It is fundamental in digital systems for data storage, signal synchronization, and transferring data between different parts of the system.

**Q9: The greatest negative number which can be stored in a computer that has 8-bits work length and uses 2's complement arithmetic is:**

- **(B)** -217
- **(C)** -255
- **(D)** -128

**Answer:** **(D) -128**

**Explanation:** In an 8-bit system with 2's complement representation, the range is from -128 to 127. The most negative number is -128, represented as 10000000 in binary.

**Q21: Which command loads a new version of the Cisco IOS into a router?**

- **(A)** copy flash ftp
- **(B)** copy ftp flash
- **(C)** copy flash tftp
- **(D)** copy tftp flash

**Answer:** **(D) copy tftp flash**

**Explanation:** copy tftp flash copies a new IOS image from a TFTP server into the router’s Flash — Cisco’s standard documented procedure for loading a new IOS version. copy ftp flash also works if the image sits on an FTP server, but copy flash ftp / copy flash tftp copy the image OUT of the router, not into it.

**Q24: A CPU generates 32-bit virtual addresses. The page size is 4 KB. The processor has a translation look-aside buffer (TLB) which can hold a total of 128 page table entries and is 4-way set associative. The minimum size of the TLB tag is:**

- **(A)** 11 bits
- **(B)** 13 bits
- **(C)** 15 bits
- **(D)** 20 bits

**Answer:** **(C) 15 bits**

**Explanation:** Calculating the TLB tag size involves understanding the page size and the address space. Given the setup, 15 bits is the correct minimum size for the TLB tag.

**Q25: Page fault occurs when:**

- **(A)** When a requested page is in memory
- **(B)** When a requested page is not in memory
- **(C)** When a page is corrupted
- **(D)** When an exception is thrown

**Answer:** **(B) When a requested page is not in memory**

**Explanation:** A page fault occurs when a program tries to access a page that is not currently loaded in physical memory. The operating system then loads the required page from disk into memory, allowing the program to continue.

**Q26: When a host on network A sends a message to a host on network B, which address does the router look at?**

- **(A)** Port
- **(B)** Physical
- **(C)** IP
- **(D)** Subnet Mask

**Answer:** **(C) IP**

**Explanation:** Routers use IP addresses to forward packets between different networks. When a host on network A sends a packet to a host on network B, the router checks the destination IP address to determine the correct path for routing the packet to its destination.
