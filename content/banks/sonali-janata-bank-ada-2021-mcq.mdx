**Q10: How can you rollback a committed transaction in any DBMS?**

- **(A)** Using SQL rollback commands,
- **(B)** Restoring the data from backups,
- **(C)** Run the transaction again in Reverse order,
- **(D)** All of the above

**Answer:** **(D) All of the above**

**Explanation:** Rollback operations in a DBMS can be done using SQL rollback commands, by restoring from backups, or reversing the transaction, all of which return the database to a consistent state.

**Q11: LGWR process writes information into-**

- **(A)** Database files,
- **(B)** Control Files,
- **(C)** Redo log files,
- **(D)** All of the above

**Answer:** **(C) Redo log files,**

**Explanation:** LGWR (Log Writer) is a process in Oracle that writes redo log entries to the redo log files. These files are essential for recovery operations in case of failure.
