**Q6: Which of the following data structures is more suitable for graph representation in Floyd-Warshall Algorithm?**

- **(A)** Adjacency Matrix
- **(B)** Adjacency List
- **(C)** Incidence Matrix
- **(D)** Incidence List

**Answer:** **(A) Adjacency Matrix**

**Explanation:** Floyd-Warshall is an algorithm used to find shortest paths between all pairs of vertices in a weighted graph. It works best with an adjacency matrix representation. The adjacency matrix is a square matrix where the elements indicate whether pairs of vertices are adjacent or not, which is useful for the algorithm's calculations.

**Q7: Which of the following is not a method of the Thread class?**

- **(A)** sleep (long msec)
- **(B)** stop()
- **(C)** go()
- **(D)** yield()

**Answer:** **(C) go()**

**Explanation:** The Thread class has the sleep(), stop(), and yield() methods, but it does not have a method called go(). The sleep() method makes the thread pause for a specific time, stop() is deprecated but was used to stop a thread, and yield() gives up the CPU to allow other threads to execute.

**Q8: Which of the following statements is correct regarding abstract classes?**

- **(A)** An abstract class has no use until it is extended by some other class.
- **(B)** An abstract class has no use until it is extended by some other class.
- **(C)** It cannot be instantiated.
- **(D)** It can have constructors and static methods.

**Answer:** **(C) It cannot be instantiated.**

**Explanation:** An abstract class cannot be instantiated directly. It is designed to be subclassed by concrete classes that implement its abstract methods. Option b is correct in saying it can have non-abstract (concrete) methods. Option d is also true; abstract classes can have constructors and static methods. However, the key point is that an abstract class cannot be instantiated, which makes option c the most accurate.

**Q9: The feature in object-oriented programming that allows the same operation to be carried out differently, depending on the object, is:**

- **(A)** Inheritance
- **(B)** Polymorphism
- **(C)** Over-functioning
- **(D)** Overriding

**Answer:** **(B) Polymorphism**

**Explanation:** Polymorphism is the concept in object-oriented programming that allows a single function or method to work differently based on the type of object that calls it. This is commonly used to implement method overriding and method overloading, allowing for dynamic behavior depending on the object.

**Q10: In the following graph, determine the cost of the shortest path between node 1 and node 4.**

- **(A)** 0
- **(B)** 4
- **(C)** -5
- **(D)** ∞

**Answer:** **(D) ∞**

**Explanation:** Dijkstra's algorithm finds the shortest path between two nodes, but it assumes all edge weights are non-negative. The presence of negative weights in the graph (such as -7 and -5) can result in cycles where the path length can continuously decrease, causing Dijkstra's algorithm to fail. As a result, there is no valid shortest path between node 1 and node 4, making the correct answer infinity (∞).

**Q11: Suppose you are searching student data using student number as the key. Which of the following arrangements of the student data is suited for binary search?**

- **(A)** Student data are arranged in the positions indicated by the student numbers' hash values.
- **(B)** Student data are arranged randomly irrespective of the student numbers.
- **(C)** Student data are arranged in ascending order of student numbers.
- **(D)** Student data are arranged in the order of the cell addresses of the student numbers' locations.

**Answer:** **(C) Student data are arranged in ascending order of student numbers.**

**Explanation:** Binary search requires that the data be sorted. For a binary search to work efficiently, the data must be arranged in a sequence, typically in ascending order, so that the algorithm can iteratively split the search space in half. If the data is not sorted, binary search cannot function as intended.

**Q15: An n x n array v is defined as follows: v[i, j] = i - j for all i, j, 1 ≤ i ≤ n, 1 ≤ j ≤ n The sum of the elements of the array v is:**

- **(A)** 0
- **(B)** n - 1
- **(C)** n² - 3n + 2
- **(D)** n²(n + 1)/2

**Answer:** **(A) 0**

**Explanation:** In the given matrix, the elements are formed by subtracting the column index j from the row index i, i.e., v[i, j] = i - j. When you sum the entire matrix, the sum of each row and column will cancel out. Specifically, the sum of all elements of any row is 0 because each positive and negative term will offset one another. Thus, the sum of the entire matrix is 0.
