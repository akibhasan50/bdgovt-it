**Q2: What is a Universal Gate? Prove that the NAND Gate is a Universal Gate.**

**Answer:** A Universal Gate is a logic gate that can be used to implement any Boolean function (i.e., any logic circuit).

**Explanation:** **Universal Gate**

A **Universal Gate** is a logic gate that can be used to implement **any Boolean function** (i.e., any logic circuit). If we can build the basic gates **NOT**, **AND**, and **OR** using only one type of gate, then that gate is called a universal gate.

**Proof: NAND is a Universal Gate**

To prove NAND is universal, we show that we can construct **NOT**, **AND**, and **OR** using only NAND gates.

Since we can build **NOT**, **AND**, and **OR** using only NAND gates, we can build any Boolean expression. Therefore, the **NAND gate is a Universal Gate**.

**Q3: Explain how any Boolean function can be implemented using only universal gates.**

**Answer:** Universal gates are logic gates that can implement any Boolean function without using any other type of gate.

**Explanation:** The two universal gates are:

- NAND Gate
- NOR Gate

Using only NAND gates or only NOR gates, all basic logic gates such as AND, OR, and NOT can be constructed. Since any Boolean function is built using these basic gates, any Boolean function can also be implemented using universal gates.

**Implementation Using NAND Gate**

**1. NOT Gate using NAND**

When both inputs of a NAND gate are connected together:

Y=overline(A· A)=overline(A)

**2. AND Gate using NAND**

First NAND operation gives:

`(A · B)'
`

Applying another NAND as NOT operation:

Y=overline(overline(A· B))=A· B

**3. OR Gate using NAND**

Using De Morgan’s theorem:

A+B=overline(overline(A)·overline(B))

So OR gate can also be implemented using only NAND gates.

**Implementation Using NOR Gate**

**1. NOT Gate using NOR**

When both inputs are same:

Y=overline(A+A)=overline(A)

**2. OR Gate using NOR**

First NOR operation gives:

`(A + B)'
`

Applying another NOR as NOT operation:

Y=overline(overline(A+B))=A+B

**3. AND Gate using NOR**

Using De Morgan’s theorem:

A· B=overline(overline(A)+overline(B))

Since NAND and NOR gates can create all basic logic gates, and all Boolean functions are formed using basic gates, any Boolean function can be implemented using only NAND gates or only NOR gates.

## Multiplexer/Demultiplexer

**Q4: What is the difference between a Multiplexer and a Demultiplexer? Explain one practical application of each in digital systems.**

**Answer:** | Multiplexer (MUX) | Demultiplexer (DEMUX) |

**Explanation:** **Difference Between Multiplexer (MUX) and Demultiplexer (DEMUX)**

| Multiplexer (MUX) | Demultiplexer (DEMUX) |
|---|---|
| A Multiplexer (MUX) is a digital circuit that selects one input from multiple input lines and forwards it to a single output line. | A Demultiplexer (DEMUX) is a digital circuit that receives data from one input line and routes it to one of multiple output lines. |
| Many Inputs → One Output. | One Input → Many Outputs. |
| Uses Select Lines to choose one input. | Uses Select Lines to choose the destination output. |
| Acts as a Data Selector. | Acts as a Data Distributor. |
| Reduces the number of communication lines. | Distributes data to different devices or destinations. |

**Practical Applications**

**Multiplexer (MUX):**
Used in **Communication Systems** to transmit multiple signals over a single communication channel, reducing wiring and transmission cost.

**Demultiplexer (DEMUX):**
Used at the receiving end of **Communication Systems** to separate the received data and deliver it to the correct output device or destination.

**Conclusion**

A **Multiplexer** combines multiple input signals into one output, whereas a **Demultiplexer** distributes one input signal to one of many outputs. They are widely used together in digital communication and data transmission systems.

## Basic

**Q9: Determine whether the logical statement (P -> Q) -> (P' -> Q') is a tautology, contradiction, or contingency.**

**Answer:** (P → Q) → (P' → Q')

**Explanation:** **Determine whether the logical statement:**

(P → Q) → (P' → Q')

**Apply implication rules**

P → Q ≡ ¬P ∨ Q

P' = ¬P

Q' = ¬Q

Therefore,

P' → Q' = ¬P → ¬Q

**Construct the Truth Table**

| P | Q | P → Q | P' → Q' | (P → Q) → (P' → Q') |
|---|---|---|---|---|
| T | T | T | T | T |
| T | F | F | T | T |
| F | T | T | F | F |
| F | F | T | T | T |

**Conclusion**

Final column values: **T, T, F, T**

Since the statement is **true in some cases** and **false in one case**, it is neither a tautology nor a contradiction.

**Therefore, the logical statement (P → Q) → (P' → Q') is a Contingency.**

In discrete mathematics, a contingency is a compound proposition whose truth value is neither always true (a tautology) nor always false (a contradiction). Its final outcome depends entirely on the specific truth values of its individual variables, meaning its truth table contains at least one True (T) and at least one False (F).

**Related info:** ICB, AP, 26

**Q10: Describe the important characteristics of digital IC's.**

**Answer:** Binary Representation: Digital ICs operate using binary values (0 and 1), which form the basis of digital data processing.

**Explanation:** **Important Characteristics of Digital Integrated Circuits (ICs)**

- **Binary Representation:** Digital ICs operate using binary values (0 and 1), which form the basis of digital data processing.
- **Boolean Logic:** They are designed using Boolean algebra operations such as AND, OR, and NOT to perform logical functions.
- **Compactness and Integration:** A large number of components can be integrated into a single chip, saving space and improving efficiency.
- **Low Power Consumption:** Digital ICs consume less power than analog circuits, making them suitable for portable and battery-powered devices.
- **Noise Immunity:** Binary signals provide better resistance to noise and interference, ensuring reliable operation.
- **High Speed:** Digital ICs offer fast switching between logic states, enabling high-speed data processing.
- **Reliability:** They provide stable, accurate, and consistent performance over long periods.

**Related info:** CB, AME/AHE, 23

**Q33: Which gates in Digital Circuits are required to convert a NOR-based SR latch to an SR flip-flop?**

**Answer:** **(A) Two 2 input AND gates**

**Explanation:** Two 2 input AND gates are placed with a NOR – based S – R latch to convert it to an S – R flip – flop. One AND gate is given R in one input and clock in the other. Similarly the second AND gate is given S in one input and clock in the other.

**Q34: When does a negative level triggered flip-flop in Digital Electronics changes its state?**

- **(A)** When the clock is negative
- **(B)** When the clock is positive
- **(C)** When the inputs are all zero
- **(D)** When the inputs are all one

**Answer:** **(A) When the clock is negative**

**Explanation:** A negative level triggered flip-flop (also called active-low level triggered) changes its state when the clock signal is at LOW level (0). “Negative level” means the flip-flop is enabled during the LOW (0) state of the clock As long as the clock is 0, the flip-flop can respond to input changes When the clock goes HIGH (1), it stops responding (holds its state)
