**Q46: What is the worst case time complexity of inserting n elements into an empty linked list, if the linked list needs to be maintained in sorted order?**

- **(A)** Θ(n)
- **(B)** Θ(n log n)
- **(C)** Θ(n²)
- **(D)** Θ(1)

**Answer:** **(C) Θ(n²)**

**Explanation:** If we insert elements one by one into a sorted linked list: 1st element → O(1) 2nd element → compare with 1 element → O(1) 3rd element → compare with 2 elements → O(2) … nth element → compare with (n−1) elements → O(n−1) Total comparisons: 1 + 2 + 3 + ... + (n−1) = n(n−1)/2 = Θ(n²) So, worst-case time complexity is Θ(n²).
