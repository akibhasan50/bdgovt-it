**Q21: The area of a square is three-fifths the area of a rectangle. The length of rectangle is 25 cm and breadth is 10 cm. What is the perimeter of the square?**

- **(A)** 60 cm
- **(B)** 44 cm
- **(C)** 80 cm
- **(D)** Cannot be determined

**Answer:** **≈ 49 cm — none of the given options is correct**

**Explanation:** Rectangle area = 25 × 10 = 250 cm². Square area = (3/5) × 250 = 150 cm². Side = √150 ≈ 12.25 cm, so perimeter ≈ 4 × 12.25 ≈ 49 cm. The options 60, 44 and 80 cm are all wrong, and "Cannot be determined" is wrong too — the value is fixed at ≈ 49 cm.

**Q29: Which sorting algorithm is best for linked list with minimum time complexity?**

- **(A)** Bubble Sort
- **(B)** Quick Sort
- **(C)** Heap Sort
- **(D)** Merge Sort

**Answer:** **(D) Merge Sort**

**Explanation:** Merge Sort is best suited for linked lists because it does not require random access and works efficiently with sequential access. It has O(n log n) time complexity and can be implemented without extra space for array indexing. Quick Sort and Heap Sort are less efficient for linked lists due to lack of random access.

**Q30: Let P be a singly linked list. Let Q be the pointer to an intermediate node x in the list. What is the worst-case time complexity of the best known algorithm to delete the node x from the list?**

- **(A)** O(n)
- **(B)** O(log n)
- **(C)** O(1)
- **(D)** O(n²)

**Answer:** **(A) O(n)**

**Explanation:** If we are given a pointer to the node x (and it is not the last node), we can delete it in constant time. Copy the data from the next node into x, then update the next pointer to skip the next node. This avoids traversing the list, so the time complexity is O(1).

**Q31: In a doubly linked list, the number of pointers affected in insertion operation will be—**

- **(A)** 5
- **(B)** 0
- **(C)** 1
- **(D)** None of these

**Answer:** **(D) None of these**

**Explanation:** Inserting a node in a doubly linked list typically requires updating 4 pointers: The new node’s next pointer, The new node’s previous pointer, The previous node’s next pointer, The next node’s previous pointer. Since 4 is not among the options, the correct answer is None of these.

**Q32: The time required to search an element in a linked list of length n is—**

- **(A)** O(log n)
- **(B)** O(n)
- **(C)** O(1)
- **(D)** O(n²)

**Answer:** **(B) O(n)**

**Explanation:** In a linked list, elements are stored sequentially and there is no random access. To find an element, we may need to traverse from the head to the end in the worst case. Thus, the time complexity for searching is O(n).

**Q35: What is the class and subnet bits if the subnet mask is 255.224.0.0?**

- **(A)** Class A, 8
- **(B)** Class A, 3
- **(C)** Class B, 3
- **(D)** Class B, 32

**Answer:** **(B) Class A, 3**

**Explanation:** The mask 255.224.0.0 in binary is: 11111111.11100000.00000000.00000000 This corresponds to /11 (8 bits from first octet + 3 bits from second octet). Class A default mask is /8, so the extra subnet bits are 11 − 8 = 3. Therefore, it is Class A with 3 subnet bits.

- **(B)** 1 2 3 4
- **(C)** 4 4 4 4
- **(D)** 0 0 0 0

**Answer:** **(A) 4 3 2 1**

**Q37: Which of the following is not a storage class specifier in C?**

- **(A)** auto
- **(B)** register
- **(C)** static
- **(D)** extern
- **(E)** volatile

**Answer:** **(E) volatile**

**Explanation:** auto, register, static, and extern are storage class specifiers in C. volatile is a type qualifier, not a storage class specifier. It tells the compiler that the variable’s value may change unexpectedly and prevents certain optimizations.

**Q38: In C, static storage class cannot be used with—**

- **(A)** Global variable
- **(B)** Function parameter
- **(C)** Function name
- **(D)** Local variable

**Answer:** **(B) Function parameter**

**Explanation:** The static storage class can be used with global variables and local variables. It can also be used with functions to restrict their scope to the file. However, static cannot be used with function parameters because parameters are automatically created and destroyed during function calls.

**Q39: Which storage class has global visibility in C/C++?**

- **(A)** Auto
- **(B)** Extern
- **(C)** Static
- **(D)** Register

**Answer:** **(B) Extern**

**Explanation:** The extern storage class gives a variable global visibility across multiple files. It allows a variable defined in one file to be accessed in another file. auto and register have local scope, while static limits visibility to the same file.

**Q40: Output of: int y = 0; int x = (y != 0); printf("%d", x);**

- **(A)** 0
- **(B)** 1
- **(C)** Negative number
- **(D)** Compiler error

**Answer:** **(A) 0**

**Explanation:** The expression (y != 0) checks whether y is not equal to 0. Since y = 0, the condition is false. In C, false evaluates to 0. Therefore, x becomes 0 and the output is 0.
