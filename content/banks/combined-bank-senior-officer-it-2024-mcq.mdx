**Q42: In which flip-flop will be the next output?**

- **(B)** J-K
- **(C)** D
- **(D)** T

**Answer:** **(C) D**

**Explanation:** In a D (Data) flip-flop, the next output directly follows the input value at the clock edge. The characteristic equation is Q(next) = D. This means the next state of the output is exactly the value of the D input, making it simple and predictable compared to other flip-flops.

**Answer:** **(D) Frame table**

**Q46: A system has 6 identical resources and N processes competing for them. Each process can request at most 2 resources. Which one of the following values of N could lead to a deadlock?**

- **(A)** 1
- **(B)** 2
- **(C)** 3
- **(D)** 4

**Answer:** **(D) 4**

**Explanation:** Deadlock can occur if every process holds one resource and waits for another. With 4 processes, each could hold 1 resource (total used = 4) and wait for one more. If the remaining resources are not sufficient to satisfy any waiting request pattern, a circular wait may occur. Thus, N = 4 can lead to a deadlock scenario.

**Q47: A counting semaphore was initialized to 10. Then 6 wait operations and 4 signal operations were completed on the semaphore. The resulting value of the semaphore is—**

- **(A)** 0
- **(B)** 10
- **(C)** 8
- **(D)** 12

**Answer:** **(C) 8**

**Explanation:** Initial semaphore value = 10. Each wait operation decreases the semaphore by 1: 10 − 6 = 4. Each signal operation increases the semaphore by 1: 4 + 4 = 8. Therefore, the final value of the semaphore is 8.

**Q67: How many select line would be there if the inputs of a MUX are 8?**

- **(B)** 3
- **(C)** 4
- **(D)** 5

**Answer:** **(B) 3**

**Explanation:** The number of select lines in a multiplexer is given by the relation: 2ⁿ = number of inputs. For 8 inputs: 2ⁿ = 8. Taking log₂ on both sides gives n = 3. Therefore, 3 select lines are required for an 8-input multiplexer.

**Explanation:** In a decoder, the number of output lines is given by 2ⁿ, where n is the number of input lines. For 4 input lines: 2⁴ = 16. Therefore, the decoder will have 16 output lines.
