**Q3: In the diagram shown below. L1 is an Ethernet LAN and L2 is a Token-Ring LAN.An IP packet originates from sender S and traverses to R, as shown. The link withineach ISP, and across two ISPs, are all point to point optical links. The initial value of TTL is 32. The maximum possible value of TTL field when R receives the datagram is-**

- **(A)** 25
- **(B)** 24
- **(C)** 26
- **(D)** 28

**Answer:** **(C) 26**

**Explanation:** The TTL (Time to Live) field in a packet decreases by 1 every time it passes through a router. If there are 6 routers between the sender and receiver, the TTL will reduce by 6. Starting from 32, the TTL when it reaches R would be 32−6=26

**Q5: Which statement is FALSE regarding a bridge?**

- **(A)** Bridge is a layer 2 device
- **(B)** Bridge reduces collision domain
- **(C)** Bridge is used to connect two or more LAN segments
- **(D)** Bridge reduces broadcast domain

**Answer:** **(D) Bridge reduces broadcast domain**

**Explanation:** A bridge operates at Layer 2 of the OSI model, connecting different segments of a network. It separates collision domains (reducing network collisions) but does not reduce the broadcast domain. Broadcasts will still propagate across all segments connected by a bridge.

**Q9: Distance vector routing algorithm is a dynamic routing algorithm. The routing tables in distance vector routing algorithm are updated ___.**

- **(A)** automatically
- **(B)** by server
- **(C)** with back up database
- **(D)** by exchanging information with neighbor nodes

**Answer:** **(D) by exchanging information with neighbor nodes**

**Explanation:** Distance-vector routing protocols, like RIP, update routing tables by exchanging information with directly connected neighbors. This allows routers to learn the best path based on distance (hop count).

**Q16: Count to infinity is a problem associated with**

- **(A)** link state routing protocol
- **(B)** istance vector routing protocol
- **(C)** DNS while resolving host name
- **(D)** TCP for congestion control

**Answer:** **(B) istance vector routing protocol**

**Explanation:** Distance vector routing protocols like RIP suffer from the "count to infinity" problem. When a network failure occurs, routers using this protocol may continuously update their routing tables with increasingly large hop counts until reaching a maximum limit, causing delays in identifying failed paths.

**Q21: Assume that Source S and Destination D are connected through an intermediate router R. How many times a packet has to visit the network layer and data link layer during a transmission from S to D?**

- **(A)** Network layer - 4 times, Data link layer - 4 times
- **(B)** Network layer - 4 times, Data link layer - 6 times
- **(C)** Network layer - 2 times, Data link layer - 4 times
- **(D)** Network layer - 3 times, Data link layer - 4 times

**Answer:** **(B) Network layer - 4 times, Data link layer - 6 times**

**Explanation:** The packet will pass through the network layer and data link layer at the source, router, and destination. Each transition involves visiting the data link layer twice (entering and exiting each device) and the network layer once. Hence, the network layer is visited 4 times (once per transition point) and the data link layer is visited 6 times.

**Q23: What is the split horizon?**

- **(A)** Information about a route should not be sent back in the direction from which the original update came.
- **(B)** It splits the traffic when you have a large bus (horizon) physical network
- **(C)** It prevents regular update messages from reinstalling a route that has gone down.
- **(D)** It holds the regular updates from broadcasting to a downed link.

**Answer:** **(A) Information about a route should not be sent back in the direction from which the original update came.**

**Explanation:** Split horizon is a technique used in distance-vector routing to prevent routing loops. It prevents a router from advertising a route back onto the interface from which it was learned, reducing the chances of incorrect route information being spread.

**Q24: What is routing poisoning?**

- **(A)** It sends back the protocol received from a router as a poison pill, which stops the regular updates.
- **(B)** It is information received from a router that can’t be sent back to the originating router.
- **(C)** It prevents regular update messages from reinstalling a route that has just come up.
- **(D)** It describes when a router sets the metric for a downed link to infinity.

**Answer:** **(D) It describes when a router sets the metric for a downed link to infinity.**

**Explanation:** Routing poisoning is a method used in distance-vector routing protocols to prevent routing loops. When a link fails, the router sets the route's metric to an infinite value, indicating that the path is no longer available.

**Q26: Suppose that a class A is defined with two variables name1, name2 and three methods with arguments int f1(int), void f2(String) and String f3(String, int). Then choose which one of the following cannot be asked in a class B which is extended from A?**

- **(A)** int f1(int)
- **(B)** int f1(String)
- **(C)** int f2(String)
- **(D)** int f2(int)

**Answer:** **(C) int f2(String)**

**Explanation:** Class B cannot declare int f2(String): it has the same method signature f2(String) as A’s void f2(String) but an incompatible return type (int vs void), so it cannot override it.
